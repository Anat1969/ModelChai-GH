# יוצר: מתמטיקה

מתמטיקה הפוכה: אפליקציה שמתרגמת מושג מתמטי למתכון גאומטרי, ובונה ממנו מודל תלת-ממדי בשתי רמות, ערום וריאליסטי.

## מצב
**שלב 0 הושלם:** הקמה, החוזה (`src/recipe/schema.ts`) והכללים הסמנטיים (`src/recipe/rules.ts`). השלב הבא: שלב 1, מנוע הסוויפ. ראו `docs/BUILD_PLAN.md`.

npm test          # vitest
