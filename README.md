# יוצר: מתמטיקה

מתמטיקה הפוכה: אפליקציה שמתרגמת מושג מתמטי למתכון גאומטרי, ובונה ממנו מודל תלת-ממדי בשתי רמות, ערום וריאליסטי.

## מצב
**כתובת חיה:** https://math-creator.vercel.app. כל דחיפה לענף ברירת המחדל נפרסת לבד.

- **שלב 0:** החוזה (`src/recipe/schema.ts`) והכללים הסמנטיים (`src/recipe/rules.ts`).
- **שלב 1:** מנוע הסוויפ ב-`src/engine`, ב-Worker. המדדים נבדקים מול חישוב אנליטי, בסטייה של עד 0.5%.
- **שלב 2:** סטודיו עם המודל הערום, מדדים, ארבע מצלמות, מעקב אחרי הקצה, חתך נע, וייצוא ל-glTF, OBJ, STL, JSON ו-PNG.
- **שלב 3:** מסך "מושג חדש" ופונקציית השרת `concept-to-recipe`, עם לולאת תיקון. נבדק מול Claude: 5 מתוך 5 מושגים תקינים, ומושג עד מודל תוך 22 שניות.
- **שלב 4:** הרמה הריאליסטית: שמש מ-suncalc, עונות, מזג אוויר, שישה חומרים, ארבעה הקשרים, אנשים, ופרומפט להמחשה. מעבר בין הרמות לא בונה את המודל מחדש.
- **שלב 5:** פרויקטים, גרסאות שלא משתנות, צילומים, השוואה עם מצלמה משותפת, וטיוטות שנשמרות במכשיר.

השלב הבא הוא שלב 6: הרחבות. ראו `docs/BUILD_PLAN.md`.

## פקודות
```
npm install
npm test          # vitest: חוזה, כללים, מנוע, ייצוא
npm run e2e       # Playwright: מבחני הקבלה של שלבים 2 עד 5 בדפדפן, מול Supabase מדומה
npm run integration    # שלב 3 מול השרת: חמישה מושגים ומושג עד מודל. עולה כסף, ודורש רשת
npm run build:function # בונה את supabase/functions/concept-to-recipe/index.ts מ-src
npm run typecheck
npm run dev
```
