# GENERATORS.md — המנוע הגאומטרי

כל מחולל הוא פונקציה טהורה: `build(recipe) → { meshes, curves, metrics, issues }`. הוא רץ ב-Web Worker, לא נוגע ב-DOM ולא ב-three.js. הוא מחזיר מערכי מספרים (`Float32Array`, `Uint32Array`) שהממשק הופך לגאומטריה.

במוצר המינימלי יש מחולל אחד, **סוויפ**, שהוכח במודל "הטבעת המשולשת". בשלב 6 נוסף **המשטח הפרמטרי** (סעיף 4.1). שאר המחוללים מתוארים בסוף המסמך.

## 1. מחולל הסוויפ

### 1.1 החתך
פונקציה `section(t, k)` מחזירה נקודה דו-ממדית `(x, y)` במישור החתך, עבור `t ∈ [0, 2π)` ומקדם קנה מידה `k`. `k = 1` הוא המעטפת החיצונית, `k < 1` הוא הדופן הפנימית.

| עקומה | נוסחה (עם A = a·k) | רדיוס חוד | רדיוס פאה | שטח | היקף |
|---|---|---|---|---|---|
| `deltoid` | x = A(2cos t + cos 2t), y = A(2sin t − sin 2t) | 3A | A | 2πA² | 16A |
| `hypocycloid` (n חודים) | x = A((n−1)cos t + cos((n−1)t)), y = A((n−1)sin t − sin((n−1)t)) | nA | (n−2)A | πA²(n−1)(n−2) | 8A(n−1) |
| `circle` | x = A cos t, y = A sin t | | A | πA² | 2πA |
| `polygon` (m צלעות) | אינטרפולציה לינארית בין קודקודים ברדיוס A | A | A·cos(π/m) | | |
| `superellipse` (p) | x = A·sgn(cos t)·\|cos t\|^(2/p), y = A·sgn(sin t)·\|sin t\|^(2/p) | | | | |

- הדלתואיד הוא מקרה פרטי של ההיפוציקלואידה עם n = 3. הקוד מממש את ההיפוציקלואידה פעם אחת.
- `aspect` מכפיל את y אחרי החישוב.
- החודים של היפוציקלואידה נמצאים ב-`t = 2πj/n`. הם מחלקים את החתך ל-n קשתות.

### 1.2 המסלול והמסגרת
המסלול נותן לכל פרמטר `u` נקודה `C(u)` ומסגרת: וקטור רדיאלי `N(u)` (ציר x של החתך) ווקטור `B(u)` (ציר y של החתך).

| מסלול | C(u) | מסגרת |
|---|---|---|
| `circle` | (R cos u, h0, R sin u), ‏u ∈ [0, 2π) | N = (cos u, 0, sin u), ‏B = (0, 1, 0) |
| `ellipse` | (R cos u, h0, R2 sin u) | N = הנורמל האופקי לעקומה, B = (0, 1, 0) |
| `helix` | (R cos u, h0 + pitch·u/2π, R sin u), ‏u ∈ [0, 2π·turns] | מסגרת ממזערת סיבוב (rotation-minimizing frame), כדי שהחתך לא יתפתל מעצמו |
| `line` | (0, h0, u), ‏u ∈ [0, length] | N = (1, 0, 0), ‏B = (0, 1, 0) |
| `lemniscate` (R, cross_height) | (R cos u / (1 + sin²u), h0 + cross_height·(1 + sin u)/2, R sin u cos u / (1 + sin²u)), ‏u ∈ [0, 2π) | N = הנורמל האופקי לעקומה בתוכנית, B = T × N |
| `torus_knot` (R, r, p, q) | ((R + r cos qu) cos pu, h0 + r sin qu, (R + r cos qu) sin pu), ‏u ∈ [0, 2π) | מסגרת ממזערת סיבוב עם תיקון סגירה |
| `wave` (length, amplitude, wavelength) | (A sin(2πu/λ), h0, u), ‏u ∈ [0, length] | N = הנורמל האופקי, B = (0, 1, 0) |
| `arch` (span, height) | לפי אורך הקשת σ מהשיא: (c·asinh(σ/c), h0 + height + c − √(c² + σ²), 0), ‏u ∈ [0, 2c·sinh(span/2c)] | N = (0, 0, −1) לרוחב הקשת, B = הנורמל במישור הקשת |

**ארבעת המסלולים החדשים** (`DECISIONS.md` 130–134) כתובים פעם אחת כעקומה עם נגזרת אנליטית, והמסגרת נגזרת ממנה:
- **למניסקטה:** עקומת ברנולי. הענף שעובר בצומת ב-u = π/2 עולה ב-`cross_height`, והענף ב-u = 3π/2 נשאר ב-h0, כך שענף אחד עובר מעל השני כגשר. בשני הענפים המשיק אופקי בצומת. אורך העקומה בלי הגשר: 2ϖR (ϖ ≈ 2.622, קבוע הלמניסקטה).
- **קשר טורי:** p הקפות סביב ציר y ו-q ליפופים סביב צינור הטבעת; p = 2, q = 3 הוא קשר התלתן. מסגרת ממזערת סיבוב לא חוזרת לעצמה אחרי הקפה: היא מסתובבת בזווית ההולונומיה α. התיקון מפזר אותה לאורך ההקפה, N(u) מסובב סביב T(u) ב-α·u/2π, כך שהמסגרת נסגרת והסיבוב של החתך נסגר לפי כלל 1. בקשר התלתן R = 12, r = 5: α ≈ −131.6°.
- **גל:** לאורך ציר z כמו הקו. B אנכי, ולכן לקליפה יש רצפה. אורך גל אחד: (4/k)·√(1+m)·E(m/(1+m)), עם k = 2π/λ, m = (Ak)².
- **קשת:** שרשרת y = c(cosh(x/c) − 1) הפוכה, שעוברת ברגליים (±span/2, h0) ובשיא (0, h0 + height). c נפתר מ-height = c(cosh(span/2c) − 1) בחציה. הפרמטר הוא אורך הקשת, ולכן הדגימה אחידה גם ברגליים התלולות.
- **רזולוציה:** בקשר `path_segments × max(p, q)` שורות, בגל לפחות 120 שורות לאורך גל, ולכל היותר 6,144 שורות.

### 1.3 סיבוב וקנה מידה
- זווית החתך: `θ(u) = θ0 + 2π · turns_per_lap · (u / U)`, כאשר U הוא אורך הפרמטר של הקפה אחת (2π במעגל).
- קנה מידה גאומטרי: `s(u) = scale_along_path ^ (u / u_max)`. כך היחס בין שתי הקפות עוקבות קבוע, וזה מה שמושגים כמו יחס הזהב צריכים. דוגמה: 3 הקפות עם `scale_along_path = 0.236` נותנות יחס של 0.618, כלומר 1/φ, בכל הקפה.
- קנה המידה חל על החתך, כולל הדופן הפנימית, ולכן גם עובי הקליפה מצטמצם יחד איתו.
- נקודה במרחב:
  `(x, y) = section(t, k)`
  `(X, Y) = rotate((x, y), θ(u)) · s(u)`
  `P(u, t) = C(u) + X·N(u) + Y·B(u)`

### 1.4 טופולוגיית הרשת
- **חודים חדים:** כל קשת בין שני חודים היא רצועת רשת נפרדת, עם קודקודים כפולים בחודים. כך הנורמלים בתוך קשת חלקים, והחוד נשאר חד.
- **נורמלים:** הפרש סופי, `n = ∂P/∂u × ∂P/∂t`, עם `t` מוזז ב-ε פנימה בקצות הקשת. הכיוון נבחר כך שהנורמל פונה מהמרכז של החתך החוצה במעטפת החיצונית, ופנימה בדופן הפנימית.
- **סגירת הטבעת:** בקצה ההקפה (u = U), קשת j מתחברת לקשת `(j + k) mod n` בתחילתה, כאשר `k = n · turns_per_lap`. לייצוא רשת סגורה (STL), האינדקס בשורה האחרונה מוזז ב-`round(M · turns_per_lap) mod M`, כאשר M הוא מספר הנקודות בחתך כולו.
- **כיוון משולשים:** נבדק מול הנורמל במשולש הראשון, ומתהפך כולו אם צריך.
- **רזולוציה:** ברירת מחדל 360 × 48 לקשת בתצוגה, ו-720 × 144 בייצוא. בטלפון: חצי.

### 1.5 קליפה
- הדופן הפנימית היא אותו חתך עם `k = (a − t) / a`, כאשר t הוא עובי הדופן.
- תוצאה: עובי t בפאות ו-3t בחודים בדלתואיד (n·t בהיפוציקלואידה). **החוד הופך לצלע.** זו תכונה מכוונת, לא קירוב.
- `inner_method: "normal_offset"` (היסט לאורך הנורמל, עובי אחיד) עוד לא נבנה בסוויפ. במשטח הפרמטרי הקליפה היא תמיד היסט נורמלי (סעיף 4.1).

### 1.6 פתחים
פתח הוא הסרת מרובעים מהרשת. הוא מוחל על שתי הדפנות באותו אזור פרמטרי, כדי שהחורים יתיישרו.

- **פסי אור (`slots`):** מרובע מוסר כאשר מיקומו היחסי בקשת `σ` מקיים `|σ − 0.5| < width_fraction / 2`, וגם `frac(u · count / U) < duty`. הפסים יושבים במרכז כל פאה ומסתובבים איתה.
- **מעברים (`passages`):** מרובע מוסר כאשר `|Δu| · R < width / 2` סביב זווית מעבר, וגם הגובה שלו בטווח `[level − 0.8, level + height]`. זוויות המעברים: `start + i · 360 / count`.
- **מעברים רק בטבעת:** מעבר פותח טבעת אל החצר שלה, ולכן הוא קיים רק במסלול `circle` או `ellipse` (`DECISIONS.md` 130).
- **משקוף:** בתצוגה שפת הפתח פתוחה. ברשת הסגורה של קובץ ההדפסה כל פתח נסגר סביב שפתו ברצועת משקוף: לכל צלע בשפת החור בדופן החיצונית a→b נוסף המרובע b, a, a′, b′ אל אותה צלע בדופן הפנימית. החורים נקבעים פעם אחת מהדופן החיצונית, ולכן שתי השפות עוברות באותן נקודות רשת, והגוף נשאר אטום ומכוון (`DECISIONS.md` 133). במסלול פתוח נשארת שורת דופן אחת ליד כל מכסה.
- **חלק הפתחים** מחושב כסכום שטחי המרובעים שהוסרו מהמעטפת החיצונית, חלקי השטח הכולל.

### 1.7 רצפה
- הרצפה היא מישור `y = level` בתוך החתך הפנימי.
- **מיתר הרצפה:** לכל u, דוגמים את החתך הפנימי ב-360 נקודות, מוצאים את כל החיתוכים עם `y = level`, ממיינים, ומחברים לזוגות `[x0, x1], [x2, x3]…`. הזוג הארוך ביותר הוא הרצפה. כיוון שהעקומה סגורה ופשוטה, כל זוג הוא קטע פנימי.
- רשת הרצפה היא רצועה בין המיתרים ב-u עוקבים. קטע ללא מיתר הוא קטע ללא רצפה.

### 1.8 הקצה הרציף
- חוד j בהקפה מספר L נמצא ב-`t = 2π(j + L·k) / n`.
- מספר הקצוות: `gcd(n, k)`. כאשר k = 0: n קצוות.
- כל קצה מקיף את המסלול `n / gcd(n, k)` פעמים.
- עקומת הקצה מוזזת 5 ס"מ החוצה מהמשטח, כדי שלא תיבלע בו בתצוגה.

## 3. בדיקות חובה (vitest)
1. מתכון `fixtures/umbilic-torus.recipe.json` בגרסת גוש עם R = 12, a = 1.2: נפח הרשת הסגורה בתוך 0.5% מ-2πa²·2πR (≈ 682.2 מ"ק).
2. רשת הייצוא סגורה: כל צלע משותפת לשני משולשים בדיוק.
3. `turns_per_lap = 1/3` → קצה אחד. `0` → שלושה. `2/3` → אחד.
4. גרסת הקליפה של המתכון: רוחב רצפה 3.1–8.4 מ', גובה חופשי 4.65–7.8 מ', רצפה רציפה.
5. `turns_per_lap = 0.25` עם דלתואיד מחזיר שגיאה סמנטית 1.
6. בנייה של מתכון ברירת המחדל לוקחת פחות מ-150 אלפיות שנייה ב-Worker במחשב נייד.

### 4.1 המשטח הפרמטרי (נבנה בשלב 6)
משטח `S(u, v)` ממשפחה בשם, עם המידות שלה. אין מחרוזות נוסחה: כל משפחה היא קוד שהמנוע מכיר, ולכן היא בטוחה ונבדקת מול חישוב אנליטי (`DECISIONS.md` 135). הצירים: Y למעלה, הציר האנכי עובר בראשית. הקוד: `src/engine/surface/`.

| משפחה | S(u, v) | תחום | סגירה | צד חיצוני | שטח לבדיקה |
|---|---|---|---|---|---|
| `hyperboloid` (`waist_radius` a, `end_radius` e, `height` H) | r(y)·(cos u, ·, sin u), y = v, r(y) = a√(1 + y²/c²), c = (H/2)/√(e²/a² − 1) | u ∈ [0, 2π), v ∈ [−H/2, H/2] | u סגור | הרחק מהציר | 2π∫ r√(1 + r′²) dy, סימפסון ב-4000 קטעים |
| `catenoid` (`waist_radius` c, `height` H) | r(y) = c·cosh(y/c) | כמו למעלה | u סגור | הרחק מהציר | πc(H + c·sinh(H/c)), סגור |
| `hyperbolic_paraboloid` (`span`, `span2`, `rise`) | (u, k·u·v, v), k = (rise/2)/(hx·hz) | u ∈ [−hx, hx], v ∈ [−hz, hz] | פתוח | למעלה | ∫∫√(1 + k²(u² + v²)), סימפסון כפול |
| `monkey_saddle` (`span`, `rise`) | (u, k(u³ − 3uv²), v), k = (rise/4)/h³ | ריבוע | פתוח | למעלה | ∫∫ עם נגזרות מדויקות |
| `helicoid` (`radius` R, `pitch` p, `turns` n) | (v cos u, c·u, v sin u), c = p/2π | u ∈ [0, 2πn], v ∈ [0, R] | פתוח | למעלה | U·(R/2·√(R² + c²) + c²/2·asinh(R/c)), סגור |
| `klein_bottle` (`radius` R, `tube` a) | ρ = R + a(cos(u/2) sin v − sin(u/2) sin 2v), (ρ cos u, a(sin(u/2) sin v + cos(u/2) sin 2v), ρ sin u) | u, v ∈ [0, 2π) | u סגור בהיפוך v → −v, v סגור | אין, חד-צדדי | אינטגרציה נומרית ב-1600 × 800 |

- **נורמל:** `S_u × S_v`, נגזרות בהפרש מרכזי. הכיוון החיצוני נבחר פעם אחת בנקודה פנימית, לפי עמודת "צד חיצוני".
- **קליפה בהיסט נורמלי:** שתי יריעות ב-`S ± (t/2)·n`, כך שהעובי אחיד בכל המשטח. לאורך כל שפה פתוחה של התחום, רצועה מחברת את שתי היריעות, ולכן הגוף סגור: כל צלע משותפת לשני משולשים, פעם בכל כיוון. בבקבוק קליין אין שפה: בתפר הנורמל מתהפך, והיריעה החיצונית ממשיכה ביריעה הפנימית. השפה של משטח חד-צדדי מעובה היא משטח סגור אחד, דו-צדדי.
- **נפח:** `t · A`, כאשר A הוא שטח משטח האמצע (∫∫|S_u × S_v|, נקודת אמצע ב-400 × 200). האיבר הבא, `(t³/12)·∫K dA`, קטן מ-0.1% בכל עובי שהסכמה מאפשרת.
- **מיקום:** הנקודה הנמוכה של הקליפה עומדת בגובה `bare.section_center_height`. אפס: על הקרקע. ערך שלילי: שקוע כמו יסוד (`DECISIONS.md` 136).
- **קצוות:** השפות של משטח האמצע, כלולאות סגורות: שתי טבעות במגדל, לולאה אחת באוכף וברמפה, אף אחת בבקבוק קליין. הקו המצויר מוזז 5 ס"מ החוצה מהשפה.
- **רזולוציה:** ברירת מחדל לכל משפחה (192 × 64 במגדלים ובקליין, 96 × 96 באוכפים, ‏96 לסיבוב × 32 ברמפה). בייצוא: פי שניים בכל כיוון. `resolution.u_segments`, `v_segments` במתכון גוברים.
- **לא נבנה עדיין:** פתחים ורצפה במשטח, וסימון הקווים הישרים של משטח ישר-קווי.
