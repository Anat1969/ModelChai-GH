המתכון הוא החוזה היחיד בין שלושה צדדים: **Claude** שמתרגם מושג למתכון, **המנוע** שבונה ממנו גאומטריה, ו**הממשק** שמכייל אותו. כל מה שנשמר, משוחזר או מושווה הוא מתכון.

- סכמה פורמלית: `docs/schema/recipe.schema.json` (JSON Schema 2020-12).
- מתכון לדוגמה, שעובר את הסכמה: `docs/fixtures/umbilic-torus.recipe.json`.
- בקוד: הסכמה מתורגמת ל-zod, וזה מקור האמת לטיפוסים ב-TypeScript.

## המחולל במוצר המינימלי: סוויפ
חתך דו-ממדי נע לאורך מסלול, מסתובב בתוך המישור שלו, ואופציונלית משנה קנה מידה.

| שדה | משמעות | טווח |
|---|---|---|
| `section.curve` | צורת החתך: `deltoid`, `hypocycloid`, `circle`, `polygon`, `superellipse` | |
| `section.a` | מקדם גודל. בדלתואיד: חודים ב-3a, פאות ב-a | 0.1–20 |
| `section.cusps` | מספר חודים, רק ב-`hypocycloid` | 3–8 |
| `section.sides` | מספר צלעות, רק ב-`polygon` | 3–12 |
| `section.exponent` | מעגליות, רק ב-`superellipse` | 0.3–8 |
| `section.aspect` | יחס גובה לרוחב של החתך. 1 = ללא מתיחה. ערך נמוך יוצר רצועה שטוחה, כמו ברצועת מביוס | 0.03–1 |
| `path.type` | `circle`, `ellipse`, `helix`, `line` | |
| `path.R` | רדיוס המסלול | 0.5–300 |
| `twist.turns_per_lap` | סיבובי החתך בהקפה אחת. 1/3 = טורוס טבורי | ‎-4 עד 4 |
| `twist.initial_angle_deg` | זווית החתך בתחילת המסלול. ‎-90 = חוד כלפי מטה | |
| `scale_along_path` | יחס קנה המידה בין סוף המסלול לתחילתו | 0.1–5 |

**נוסחת הדלתואיד:** `x = a(2cos t + cos 2t)`, `y = a(2sin t − sin 2t)`.

## המחולל `parametric_surface` (שלב 6)
משטח בשם מספרייה קבועה, שנבנה כקליפה בעובי אחיד בהיסט לאורך הנורמל (`GENERATORS.md` 4.1). אין ביטויים חופשיים: `params` הוא אובייקט סגור, וכל שדה אחר נדחה.

| שדה | משמעות | טווח | נדרש ב- |
|---|---|---|---|
| `family` | `hyperboloid`, `hyperbolic_paraboloid`, `catenoid`, `helicoid`, `klein_bottle`, `monkey_saddle` | | תמיד |
| `waist_radius` | רדיוס המותן | 0.5–100 | `hyperboloid`, `catenoid` |
| `end_radius` | רדיוס הטבעות בקצוות | 0.5–150 | `hyperboloid` |
| `height` | גובה בין הטבעות | 1–200 | `hyperboloid`, `catenoid` |
| `span`, `span2` | מפתחי התוכנית. בלי `span2` התוכנית ריבועית | 1–200 | `span`: `hyperbolic_paraboloid`, `monkey_saddle` |
| `rise` | הפרש הגובה בין הנקודה הגבוהה לנמוכה במשטח האמצע | 0.5–100 | `hyperbolic_paraboloid`, `monkey_saddle` |
| `radius` | רדיוס הרמפה, או רדיוס הטבעת בבקבוק קליין | 0.5–150 | `helicoid`, `klein_bottle` |
| `pitch` | העלייה בסיבוב אחד | 0.5–50 | `helicoid` |
| `turns` | מספר סיבובים | 0.25–10 | `helicoid` |
| `tube` | חצי הגובה של חתך השמינייה | 0.2–50 | `klein_bottle` |
| `resolution.u_segments`, `v_segments` | צפיפות הרשת | 8–1024, ‏4–512 | אף פעם |

**`bare` במשטח:** `mode` חייב להיות `shell` (כלל 10), ו-`shell.thickness` הוא עובי הקליפה. `section_center_height` הוא הגובה של הנקודה הנמוכה בקליפה: אפס עומד על הקרקע, ערך שלילי שוקע. `inner_method` לא משפיע, כי המשטח תמיד בהיסט נורמלי. `openings` ו-`floor` לא נבנים במשטח (`DECISIONS.md` 137).

## כללים סמנטיים
הסכמה בודקת מבנה וטווחים. הכללים האלה בודקים שהמתכון **בונה מבנה תקף**, ונבדקים במנוע אחרי הבדיקה מול הסכמה. **שגיאה** חוסמת בנייה. **אזהרה** בונה, ומסמנת את המדד בכתום.

| # | כלל | סוג | הודעה למשתמשת |
|---|---|---|---|
| 1 | במסלול סגור, `turns_per_lap × סדר הסימטריה של החתך` חייב להיות שלם. סדר הסימטריה: דלתואיד 3, היפוציקלואידה n, מצולע מספר הצלעות, עיגול כל ערך. כש-`aspect` שונה מ-1, הסדר יורד ל-2 לכל היותר (וב-n אי-זוגי ל-1) | שגיאה | "החתך לא נסגר על עצמו בסוף ההקפה" |
| 2 | `path.R` גדול מהרדיוס המרבי של החתך (בדלתואיד: R > 3a) | שגיאה | "הטבעת חותכת את עצמה במרכז" |
| 3 | בקליפה: `thickness` קטן מרדיוס הפאה (בדלתואיד: t < a) | שגיאה | "הדופן הפנימית נעלמת" |

## מדדים נגזרים
המנוע מחשב ומחזיר אותם עם כל בנייה. הם לא נשמרים במתכון, כי הם נגזרים ממנו.

| מדד | חישוב | בדיקה |
|---|---|---|
| מספר קצוות | `gcd(n, k)` כאשר n = מספר חודים ו-k = n × turns_per_lap. כשאין סיבוב: n | טורוס טבורי: 1. בלי סיבוב: 3 |
| אורך קצה | אורך עקומת החוד, מחושב נומרית | |
| נפח | פאפוס: שטח החתך × 2πR. בדלתואיד שטח החתך הוא 2πa² | רשת סגורה מול פאפוס, סטייה עד 0.5% |
| נפח קליפה | 2π(a² − a′²) × 2πR × (1 − חלק הפתחים), כאשר a′ = a − t | |
| משקל | נפח × 2.4 טון למ"ק לבטון, לפי צפיפות החומר | |
| רוחב רצפה | מיתר הקו y = level בתוך החתך הפנימי, מינימום ומקסימום לאורך ההקפה | |
| גובה חופשי | הנקודה הגבוהה בחתך הפנימי פחות level, מינימום ומקסימום | |
| עומק חוד בקרקע | max(0, 3a − h0) | |

| נפח קליפה (משטח פרמטרי) | עובי × שטח | רשת סגורה מול t·A, סטייה עד 0.5% |

## זרימת התיקון
1. Claude מחזיר מתכון.
2. בדיקה מול הסכמה. אם נכשל: שליחה חוזרת ל-Claude עם רשימת השגיאות, עד פעמיים.
3. בדיקת הכללים הסמנטיים. שגיאה: Claude מקבל את ההודעה ומתקן פעם אחת. אזהרה: הבנייה ממשיכה.
4. אם עדיין נכשל: המתכון נפתח לעריכה ידנית, והשדה הבעייתי מסומן.

## דוגמה מלאה
ראו `docs/fixtures/umbilic-torus.recipe.json`: גרסת הקליפה של הטבעת המשולשת, עם R = 18, a = 2.4, סיבוב 1/3, עובי 0.3, שלושה מעברים ו-24 פסי אור. המתכון עובר את הסכמה, ואין בו שגיאות סמנטיות. ערכי הבדיקה: קצה אחד, רצפה רציפה ברוחב 3.1–8.4 מ', גובה חופשי 4.7–7.8 מ'.

**חריגה מכוונת:** כלל 8 מחזיר אזהרה על המתכון הזה, כי החוד קבור 5.7 מ'. זה תואם את המודל שנבנה, ומשמש כבדיקה שהאזהרה עובדת.
