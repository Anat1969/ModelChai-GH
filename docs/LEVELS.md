# LEVELS.md — שתי רמות ההמחשה

שתי הרמות מציגות **אותה רשת בדיוק**. הרמה הערומה קובעת את הצורה. הרמה הריאליסטית מלבישה אותה: חומר, אור, עונה וסביבה. מעבר בין הרמות לא בונה גאומטריה מחדש.

## 1. המודל הערום

### 1.1 מה הוא מראה
- גוון אחד בהיר, בלי טקסטורה, עם תאורה אחידה מלמעלה ושמש קבועה לצל.
- הקצה הרציף מודגש בצבע הדגש, וניתן לכבות אותו.
- קרקע נייטרלית עם רשת של מטר אחד ושל 10 מטרים, כדי שקנה המידה יהיה קריא.
- דמויות אדם פשוטות בגובה 1.75 מ'.
- חתך נע אופציונלי: מישור שחותך את המודל במקום u נבחר, ומציג את החתך הפנימי והחיצוני עם מידות.

### 1.2 פרמטרים לכיול
כל מחוון מציג ערך, יחידה, ומשפט שמסביר את השפעתו.

| קבוצה | פרמטר | שדה במתכון | משפט הסבר |
|---|---|---|---|
| גאומטריה | רדיוס הטבעת | `generator.params.path.R` | מרכז הטבעת עד מרכז החתך. קובע את גודל החצר |
| | מקדם החתך | `section.a` | החודים במרחק 3a, הפאות במרחק a |
| | סיבוב החתך | `twist.turns_per_lap` | שליש סיבוב מחבר את שלושת הקצוות לאחד |
| | יחס החתך | `section.aspect` | ערך נמוך משטיח את החתך לרצועה |
| מיקום | גובה מרכז החתך | `bare.section_center_height` | נמוך מרדיוס החוד: החוד נקבר בקרקע |
| מבנה | גוש או קליפה | `bare.mode` | בקליפה אפשר להיכנס, והבטון יורד לפחות מרבע |
| | עובי דופן | `bare.shell.thickness` | בחודים העובי משולש, ולכן החוד הופך לצלע |

| | פסי אור | `openings.slots.count`, `width_fraction` | הפסים מסתובבים עם החתך: חלון גג במקום אחד, חלון צד במקום אחר |
| רצפה | מפלס רצפה | `bare.floor.level` | הרצפה רציפה רק כשהיא חוצה את החתך הפנימי בכל ההקפה |

### 1.2א פרמטרים של משטח פרמטרי
במתכון עם `parametric_surface` הפאנל מציג את המידות של המשפחה, ואחריהן הבסיס והעובי. אין סיבוב חתך, פתחים, רצפה או חתך נע, כי אין להם משמעות במשטח (`DECISIONS.md` 139).

| משפחה | פרמטר | שדה במתכון | משפט הסבר |
|---|---|---|---|
| היפרבולואיד | רדיוס המותן | `waist_radius` | הטבעת הצרה באמצע. ממנה הקווים הישרים נפרשים למעלה ולמטה |
| | רדיוס הקצוות | `end_radius` | רוחב הטבעת למעלה ולמטה. ככל שהוא גדול מהמותן, המותן נראית צרה יותר |
| היפרבולואיד, קטנואיד | גובה | `height` | המרחק בין שתי הטבעות. בקטנואיד גובה רב פותח את הקצוות במהירות |
| קטנואיד | רדיוס המותן | `waist_radius` | הטבעת הצרה. היא קובעת גם כמה מהר המשטח נפתח כלפי הקצוות |
| אוכף, אוכף קוף | מפתח, מפתח בכיוון השני | `span`, `span2` | רוחב התוכנית. מפתח גדול עם עלייה קטנה משטיח את האוכף |
| | עלייה | `rise` | ההפרש בין הפינה הגבוהה לנמוכה. היא מכפילה את העיקול ואת הקשיחות של הקליפה |
| הליקואיד | רדיוס, פסיעה, מספר סיבובים | `radius`, `pitch`, `turns` | הפסיעה היא גם הגובה החופשי בין שני סיבובים |
| בקבוק קליין | רדיוס הטבעת, גודל השמינייה | `radius`, `tube` | השמינייה מסתובבת חצי סיבוב בהקפה, ולכן אין פנים וחוץ |
| כולן | גובה הבסיס | `bare.section_center_height` | הנקודה הנמוכה של הקליפה. ערך שלילי שוקע את הבסיס בקרקע, כמו יסוד |
| | עובי הקליפה | `bare.shell.thickness` | היסט לאורך הנורמל לשני צדי המשטח, ולכן העובי אחיד בכל מקום |

### 1.3 פאנל המדדים
המדדים מ-`GENERATORS.md` סעיף 2. מדד שחורג מכלל סמנטי מסומן בכתום, עם הודעת הכלל. לחיצה על מדד מדגישה במודל את המקום שבו הוא מתקיים, למשל את נקודת הגובה החופשי המינימלי.

## 2. המודל הריאליסטי

### 2.1 שמש ועונה
העונה היא חישוב, לא בחירה מתפריט.

- **מיקום השמש:** מספריית `suncalc`, לפי `site.lat`, `site.lon` ו-`datetime`. ברירת המחדל היא אשדוד, 31.8° צפון ו-34.65° מזרח.
- **ממשק:** מחוון תאריך (יום בשנה), מחוון שעה, וכפתורים מהירים: "היפוך חורף", "שוויון", "היפוך קיץ", "שקיעה".
- **מה נגזר מהתאריך:**

| נגזרת | חורף (דצמבר–מרץ) | אביב (אפריל–מאי) | קיץ (יוני–ספטמבר) | סתיו (אוקטובר–נובמבר) |
|---|---|---|---|---|
| צבע צמחייה | ירוק מלא | ירוק-צהוב | צהוב-חום יבש | חום, ירוק מתחיל אחרי גשם ראשון |
| לחות קרקע | כהה, רטוב אחרי גשם | בינוני | בהיר ויבש | בהיר |
| טמפרטורת אור בצהריים | 5,800K | 5,600K | 5,400K, חם יותר | 5,600K |
| אובך ברירת מחדל | נמוך | בינוני | גבוה | בינוני |

הטבלה היא **הנחת עיצוב לאקלים ים-תיכוני חופי**, ולא מודל מטאורולוגי. היא נשמרת כקובץ נתונים (`seasons.ts`) כדי שאפשר יהיה לכוונן אותה בלי לגעת בקוד.

### 2.2 מזג אוויר
| מצב | שמיים | צל | ערפל מרחק |
|---|---|---|---|
| `clear` | שיפוע לפי גובה השמש | חד | רחוק |
| `haze` | מוחלש וחם | רך | בינוני |
| `overcast` | אפור אחיד, אין שמש ישירה | כמעט אין, רק אור סביבה | קרוב |

| `fog` | חלבי, השמש עיגול חיוור | חלש ורך מאוד | הקרוב ביותר, כמה גדלי מבנה |

מזג האוויר הוא **המחשה חזותית**, לא נתוני אקלים של המקום (`DECISIONS.md` 121).

### 2.2א כיוון ורוח
- **כיוון המבנה** (`orientation_deg`): סיבוב סביב המרכז, עם כיוון השעון מהצפון. במודל כתובות המילים "צפון" ו"חזית". מתחת לשמש: זריחה, שקיעה, גובה השמש בצהריים, וכמה מעלות השמש רחוקה מכיוון החזית. מחושב מ-suncalc.
- **רוח** (`wind`): כיוון ומהירות, ועוצמה בסולם בופור במילים. קווי רוח מונפשים בגובה הקרקע ובחצי גובה המבנה, עם התווית "המחשה, לא סימולציה". הקווים עוקפים עיגול סביב טביעת הרגל לפי זרימה אידאלית, ולא את הצורה עצמה. אפשר להסיק מהם איזה צד חשוף ואיזה מוגן, ואילו מעברים פונים לרוח. אי אפשר להסיק לחץ, מערבולות או מהירות בתוך החצר (`DECISIONS.md` 122).

### 2.6 פרומפט להמחשה מהמצב
הרמה הריאליסטית מייצרת פרומפט למידג'רני **מאותם ערכים שמוצגים במסך**, כך שהתמונה והמודל מספרים את אותו סיפור.

**תבנית:**
```
{תיאור הצורה מהמתכון}, {חומר המעטפת}, {הקשר סביבתי}, {אור לפי גובה ושעת השמש}, {עונה וצמחייה}, {מזג אוויר}, {אנשים לקנה מידה}, {נקודת מבט המצלמה}, Documentary realism, Professional architecture photography, 3:2 --ar 3:2 --no text, words, writing, frame divisions
```

- הפרומפט נכתב בעברית, חוץ מהפרמטרים הקבועים.
- לפני הפרומפט מופיע משפט זיקוק אחד בעברית.
- כל פרט בפרומפט נגזר משדה במתכון. שום פרט לא נוסף רק כי הוא נשמע מרשים.
